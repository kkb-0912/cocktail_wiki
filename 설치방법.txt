내 술장 칵테일 — 앱 설치용 파일 (2026-11-13)

■ 폴더 구성
  index.html            앱 본체(레시피·술장 판정·내 술장 편집이 모두 들어 있음)
  manifest.webmanifest  앱 이름·아이콘 설정
  sw.js                 오프라인 지원
  icons/                앱 아이콘(D 시안: 선반 위 병 세 개)

■ 1단계: 인터넷 주소(https) 만들기 — 설치형 앱은 https 주소가 있어야 설치됩니다
  A) GitHub Pages
     1. GitHub에 새 저장소(repository)를 만들고 이 폴더의 파일을 전부 올립니다(폴더 구조 그대로).
     2. 저장소 Settings → Pages → Branch를 main으로 선택해 저장합니다.
     3. 잠시 뒤 https://계정이름.github.io/저장소이름/ 주소가 생깁니다.
  B) Cloudflare Pages 또는 Netlify
     폴더째로 끌어다 놓는 업로드(Direct Upload / Netlify Drop)를 지원합니다.
     계정을 만들고 폴더를 올리면 주소가 생깁니다. (메뉴 이름은 서비스마다 조금씩 다를 수 있습니다.)

■ 2단계: 휴대폰·PC에 설치
  · 아이폰(Safari): 주소 접속 → 공유 버튼 → "홈 화면에 추가"
  · 안드로이드(Chrome): 주소 접속 → 메뉴(⋮) → "앱 설치" 또는 "홈 화면에 추가"
  · PC(Chrome·Edge): 주소창 오른쪽의 설치 아이콘 → "설치"
  설치하면 홈 화면 아이콘으로 열리고, 한 번 열어 두면 인터넷이 없어도 열립니다.

■ 알아둘 점
  · 공개 범위: 레시피에 Difford's Guide와 디시인사이드 갤러리 내용이 들어 있으니 개인용으로만 쓰세요.
    주소를 아무에게나 알리지 마시고, 가능하면 접근 제한(비공개 저장소+접근 제어 등)을 거세요.
  · "내 술장 편집"으로 바꾼 술 상태는 그 기기·그 주소의 브라우저에만 저장됩니다.
    기기를 바꾸면 다시 설정해야 하고, 주소가 바뀌면 초기화됩니다.
  · 파일을 새로 올릴 때(레시피·술장 갱신): index.html을 덮어쓰고 sw.js 맨 위의 VERSION 값을 바꿔 올리세요.
    그래야 이미 설치된 앱이 새 내용으로 바뀝니다.
